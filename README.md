# To-Do List Application

A simple browser-based to-do list with filtering, due dates, and local storage,
built with HTML, CSS, and JavaScript. Includes a CI pipeline via GitHub Actions
and deployment on GitHub Pages.

## Features
- Add a task with an optional due date
- Mark tasks complete by clicking them
- Delete individual tasks
- Filter by All / Active / Completed
- Clear all completed tasks
- Tasks saved automatically in the browser (localStorage)

## Running locally
Open `index.html` in any browser.

## Running tests
```
node --test tests/
```
